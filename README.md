# A Christmas Village Editor

**Live App:** https://jasonaaronwilson.github.io/xmas-village/

This is an isometric tile based "game" like sim city for creating your cozy retro pixel art Christmas villages.

Use the mouse to select from the set of buildings and features like sleighs, snowmen, horses, carolers, etc, configure the base options, place them on the map and choose the Christmas light arrangement. Lightpolls on the streets and fireplaces inside houses all add the the ambiance.

Ctrl-z will undo mistakes. You can save your village for further editing or share with friends and families (with a customized greeting).

Press the snow button to hide the editor and begin one of three levels of realistic snow-fall. The longer the window is left, the more snow will accumulate.
